# Mini Shop

Навчальний репозиторій до практичної роботи №2 «Аналіз авторських прав на програмний код».
Це мінімальний вебзастосунок інтернет-магазину на Node.js без залежностей:
список товарів і сторінка товару з ціною.

Запуск: `npm start`, далі відкрити http://localhost:3000
